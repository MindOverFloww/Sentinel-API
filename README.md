# API Sentinel

API Sentinel is a rule-based API intrusion detection and security monitoring system.

## Structure

- `frontend/` - React + TypeScript + Vite application
- `backend/` - Spring Boot REST API
- `docs/` - project documentation, architecture notes, API specs (see [docs/PROJECT_SPECIFICATION.md](docs/PROJECT_SPECIFICATION.md))
- `scripts/` - helper scripts for setup, export, or deployment tasks

## Stack

- Frontend: React, TypeScript, Vite
- Backend: Spring Boot, Spring Security, JWT
- Database: PostgreSQL
- Deployment: cloud hosting for frontend, backend, and database

## Project Goal

Monitor real API traffic, detect suspicious patterns, calculate risk, and create security incidents.
